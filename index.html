Quick Integration

Device Configuration Guide

Activate encrypted DNS across any device in under one minute.

1

Android Private DNS (System-Wide DoT)

  1. Go to Settings > Network & Internet (or More Connections).
  2. Tap Private DNS and select Private DNS provider hostname.
  3. Enter: rbualsrzeo.cloudflare-gateway.com
  4. Tap Save. Protection is now active across all applications.
2

iOS / iPhone / iPad Configuration

  1. Open Settings > Wi-Fi > Tap the icon next to your network.
  2. Select Configure DNS > Choose Manual.
  3. Add the custom encrypted configuration profile or use dedicated DoH endpoints.
3

Windows 11 (Encrypted DNS)

  1. Open Settings > Network & internet > Wi-Fi / Ethernet.
  2. Click Hardware properties > Set DNS server assignment to Manual.
  3. Specify custom DoH settings with template encryption.
4

Chrome / Edge / Brave / Firefox

  1. Open Browser Settings > Privacy and Security > Security.
  2. Enable Use Secure DNS > Select Custom.
  3. Enter: https://rbualsrzeo.cloudflare-gateway.com/dns-query
