## 📱 How to Setup

### 🤖 Android (Native Private DNS)

1. Go to **Settings** > **Network & Internet** (or *Connections* / *More Connections*).
2. Tap **Private DNS** and choose **Private DNS provider hostname**.
3. Enter:
```text
https://dns.arman.bd

```


4. Tap **Save**. All apps and browsers are now protected.

### 🌐 Desktop Browsers (Chrome / Edge / Brave / Firefox)

1. Open Browser **Settings** > **Privacy and Security** > **Security**.
2. Enable **Use Secure DNS** and choose **Custom**.
3. Paste the DoH template:
```text
[dns.arman.bd]

```
